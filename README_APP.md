# Система обучения и тестирования сотрудников

## Описание
Десктопное приложение на Python для изучения регламента по сопровождению сделок и тестирования сотрудников.

## Требования
- Python 3.8+
- PyQt5
- reportlab

## Установка зависимостей
```bash
pip install PyQt5 reportlab
```

## Запуск приложения
```bash
python app.py
```

## Режимы работы

### 1. Изучение
Открывает удобный доступ к регламенту, который содержится в файле `reglament.json`.
- Просмотр процессов в виде структурированного списка
- Отображение шагов, условий, ограничений и шаблонов для каждого процесса
- Цветовая маркировка типов ограничений (warning, info, forbidden, important)
- Просмотр глобальных правил

### 2. Тестирование
Прохождение тестов по сценариям из файла `test_scenarios.json`.

#### Функционал:
- Ввод фамилии и имени (данные сохраняются и автоматически заполняются при повторном запуске)
- Выбор сценария от 1 до 40:
  - Сценарии 1-20: стандартные тесты
  - Сценарии 21-40: углубленные тесты
- Отображение условий сделки (видны всё время прохождения теста)
- Таймер времени прохождения (запускается при начале теста)

#### Типы вопросов:
- **single_choice** – выбор одного правильного ответа (RadioButton)
- **multiple_choice** – выбор нескольких правильных ответов (CheckBox)
- **ordering** – расстановка шагов в правильном порядке (кнопки «вверх/вниз»)
- **true_false** – утверждение, нужно выбрать «Верно» или «Неверно»

#### После завершения теста:
- Проверка ответов
- Показ результата: количество правильных/неправильных ответов
- Детализация по каждому вопросу с подсветкой ошибок (зеленый – правильно, красный – ошибка)
- Тексты объяснений на основе регламента с отсылками к разделам/пунктам
- Экспорт полного результата в PDF (ФИО, время прохождения, полный результат с описанием)
- Возможность перехода к соответствующему разделу регламента

### 3. Результаты
Просмотр всех результатов тестирования в табличном виде.

#### Таблица содержит:
- Дата и время прохождения
- Фамилия и имя тестируемого
- Номер сценария
- Количество правильных и неправильных ответов
- Кнопка "Просмотр" для детального просмотра результата
- Кнопка "Экспорт выбранного в PDF"

#### Хранение данных:
Все результаты сохраняются в файле `test_results.json` в формате JSON.

## Структура файлов
```
/workspace
├── app.py                 # Основной файл приложения
├── reglament.json         # Файл с регламентом
├── test_scenarios.json    # Файл с тестовыми сценариями
├── test_results.json      # Файл с результатами тестов (создается автоматически)
└── user_data.json         # Файл с данными пользователя (создается автоматически)
```

## Особенности реализации
- Все данные тестов хранятся в формате JSON внутри приложения
- Объяснения к вопросам формируются на основе регламента
- PDF-отчет генерируется с использованием библиотеки reportlab
- Интерфейс реализован на PyQt5 с современным стилем Fusion
